# Aplicação do guia oficial Helbor

Referência privada: Helbor_Guia-da-Marca_.pptx, slides 39–50. O manual completo não é publicado no site.

- Azul #00194C predominante; branco #FFFFFF; gráficos em turquesa #00D0D0 e dourado #D69647. Verde #75DDA0 reservado à paleta. Tons escuros secundários restritos a sobreposições gráficas conforme slide 47.
- Aktiv Grotesk para interface, Arial como alternativa de sistema autorizada no slide 49. Editorial New Italic para composições editoriais; Times New Roman como alternativa. A interface operacional usa a família sem serifa para legibilidade. Nenhuma fonte proprietária foi baixada ou incorporada.
- Logo fornecido pelo usuário mantido com símbolo, logotipo e tagline originais, sem deformação, sombra ou efeito. ViewBox ajusta somente o espaço vazio. Margens de proteção no cabeçalho.
- Nenhuma foto ou pattern do manual foi publicado. O slide 55 admite ausência de grafismos em peças com maior concentração de informação.
- Linguagem simples, próxima e direta. Quadro central e interações sob demanda preservam a facilidade de uso.
